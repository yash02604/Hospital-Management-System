# Hospital Management Systems

Hospital Management Systems is a Java desktop application built with Swing and NetBeans. The project is designed to help manage common hospital workflows such as patient registration, diagnosis entry, record updates, and history tracking.

## Features

- Login screen for entering the system
- Add new patient records
- Update existing patient details
- Add diagnosis information
- View full history of a patient
- Display hospital information

## Tech Stack

- Java
- Java Swing
- MySQL
- JDBC
- NetBeans IDE

## Project Structure

- `src/hospital/management/systems/` - Main application screens and forms
- `src/Project/Connectionprovider.java` - Database connection provider
- `dist/` - Generated build output and runnable JAR artifacts
- `nbproject/` - NetBeans project configuration files

## Getting Started

1. Open the project in NetBeans IDE.
2. Configure your MySQL database connection in `src/Project/Connectionprovider.java`.
3. Replace the placeholder values for port, username, and password with your actual database credentials.
4. Make sure the MySQL JDBC driver is available in the project libraries.
5. Build and run the project from NetBeans.

## Database Configuration

The connection file currently contains placeholder values:

- `yourport`
- `userName`
- `userPassword`

Update them before running the application.
